# EasyGPT VS Code Bridge

A localhost-only, bearer-token-authenticated API for managing VS Code integrated terminals.

## API

- `GET /v1/health`
- `GET /v1/terminals`
- `POST /v1/terminals` — create and show a terminal; optional `name` and `cwd`
- `POST /v1/terminals/:id/focus`
- `POST /v1/terminals/:id/send` — body: `{"text":"...","addNewLine":false}`
- `POST /v1/terminals/:id/execute` — body: `{"command":"...","timeoutMs":30000}`; runs via VS Code Shell Integration and returns captured output and exit code

The extension writes a short-lived connection descriptor to `%TEMP%\easygpt-vscode-bridge.json`. It contains a random bearer token and is removed when the extension deactivates.

## Safety

- Listens only on `127.0.0.1`.
- Requires the generated bearer token on every request.
- Terminal IDs are generated by the extension and are not inferred from terminal names.
- The `send` endpoint does not execute text unless `addNewLine` is explicitly true.
- The `execute` endpoint runs the supplied command in the explicitly identified terminal; use it only for commands the user has requested.
- No terminal is killed or closed by this extension.

## Development

Open this folder in VS Code and press F5 to launch an Extension Development Host.
